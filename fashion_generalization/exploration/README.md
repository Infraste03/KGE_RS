# Fashion Dataset Exploration

This directory contains exploratory scripts used to inspect the Amazon Fashion data, analyze metadata coverage, evaluate candidate preprocessing strategies, and compare the structural properties of the Fashion and B2B knowledge graphs.

These scripts are intended for dataset analysis and validation. They are not part of the final model training pipeline.

## Files

### `explore_dataset.py`

Explores the `Amazon_Fashion.jsonl.gz` dataset and its corresponding metadata.

The script:

- reads user-item interactions;
- applies iterative 3-core filtering;
- analyzes metadata coverage;
- extracts Fashion macro-categories;
- analyzes cross-category `bought_together` relationships;
- reports the distribution of Fashion categories;
- evaluates whether the resulting data provides enough interactions and KG relations for the hybrid framework.

The script writes a short final summary to:

```text
exploration/stats_output.txt
```

The complete exploratory statistics are also printed to the terminal.

Run from the repository root with:

```bash
python fashion_generalization/exploration/explore_dataset.py
```

### `explore_dataset_clothing.py`

Explores the larger `Clothing_Shoes_and_Jewelry.json.gz` dataset.

The analysis includes:

- review and metadata loading;
- Fashion category filtering;
- iterative 5-core filtering;
- sampling of up to 15,000 users;
- analysis of cross-category `also_buy` relationships;
- metadata coverage analysis;
- evaluation of the resulting data for SASRec and TransE.

Results are printed to the terminal and are not saved to a separate output file.

### `inspect_metadata.py`

Inspects the fields available in the Clothing, Shoes and Jewelry metadata.

It analyzes the first 50,000 metadata records and reports:

- field frequency;
- field coverage percentage.

This script was used to understand which metadata attributes were sufficiently populated before constructing the Fashion KG.

Results are printed to the terminal.

### `inspect_meta_2018.py`

Inspects the Clothing, Shoes and Jewelry metadata and reports:

- total number of metadata records;
- number of records containing `also_buy`;
- number of records containing `category`;
- an example record containing an `also_buy` field.

Results are printed to the terminal.

### `inspect_meta.py`

Provides a simple inspection of the raw Amazon Fashion metadata by printing the first three records.

This script is useful for checking the structure and available fields of the raw metadata before preprocessing.

### `compare_kg_stats.py`

Compares structural statistics of the B2B and Fashion knowledge graphs.

For each relation, it reports:

- number of triples;
- number of unique head entities;
- average head degree;
- maximum head degree;
- median head degree.

The comparison was used to better understand structural differences between the B2B and Fashion domains.

Results are printed to the terminal.

## Data Sources

The exploration scripts read the original datasets from:

```text
fashion_generalization/data/raw/
```

and, where required, processed Fashion KG data from:

```text
fashion_generalization/data/processed/
```

The KG comparison script additionally reads the processed B2B knowledge graph.

## Outputs

Most scripts in this directory are diagnostic tools and only print their results to the terminal.

The only persistent exploratory output generated by the scripts in this directory is:

```text
stats_output.txt
```

generated by `explore_dataset.py`.

This file contains the final summary of the 3-core Amazon Fashion exploration, including the number of users, items, interactions, cross-category KG pairs, and the resulting dataset suitability assessment.

## Dataset Selection

An initial exploration was conducted using the Amazon Fashion dataset and the corresponding `meta_Amazon_Fashion.jsonl.gz` metadata file.

The metadata file contained 826,108 product records. However, the exploratory analysis showed that the fields required to construct the knowledge graph were not populated:

```text
Total metadata records:          826,108
With populated categories:            0
With populated bought_together:       0
```

As a consequence, the initial exploration produced no usable cross-category compatibility relations:

```text
Users (3-core):                  2,792
Items (3-core):                  2,474
Total interactions:            14,728
Cross-category KG pairs:            0
```

Therefore, increasing the number of sampled users would not solve the main limitation, since the information required to construct compatibility relations was missing from the metadata itself.

For this reason, the subsequent experiments were based on the `Clothing_Shoes_and_Jewelry` dataset and its corresponding metadata. This version provides the `category` and `also_buy` information used by the exploration pipeline to identify Fashion categories and construct cross-category item relationships for the knowledge graph.
