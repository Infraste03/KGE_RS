# Fashion Generalization Experiments

This directory contains the Fashion-domain experiments used to evaluate the generalization of the knowledge-enhanced sequential recommendation framework.

The experiments are based on the Amazon **Clothing, Shoes and Jewelry** dataset and investigate whether the joint Knowledge Graph + SASRec architecture developed for the B2B domain can also provide benefits in a substantially different recommendation setting.

The Fashion experiments include:

- preprocessing and construction of sequential recommendation data;
- construction of multiple Fashion Knowledge Graph variants;
- TransE training and hyperparameter optimization;
- SASRec training and hyperparameter optimization;
- joint alternate learning between the KG and sequential recommendation tasks;
- comparison of different training schedules;
- enriched 5-relation Knowledge Graph experiments;
- Knowledge Graph ablation studies;
- alternative user-sampling strategies;
- validation and reproducibility checks.

## Naming Convention

In the paper, the two main Fashion settings are referred to as
**Fashion-Random** and **Fashion-Heavy**.

Some file names, directory names, and internal experiment identifiers retain
the historical labels used during development (e.g., `v3`) to preserve
reproducibility and compatibility with the original experimental pipeline.

### `alternate_learning/`

Contains the implementation of the joint Fashion recommendation architecture.

The architecture combines:

- **Task A:** Knowledge Graph embedding with TransE;
- **Task B:** sequential recommendation with SASRec;
- a **shared item embedding space** updated by both tasks.

The directory contains:

```text
alternate_learning/
├── checks/
├── configs/
├── hpc/
├── models/
├── variants/
│   ├── ablation_3rel/
│   ├── five_rel/
│   └── v3/
└── ...
```

The main implementation corresponds to the standard 3-relation Fashion Knowledge Graph.

Additional experimental variants are isolated under `variants/`:

- `five_rel/`: enriched KG with price and popularity information;
- `ablation_3rel/`: leave-one-relation-out ablations;
-  `v3/`: experiments corresponding to the Fashion-Heavy user-selection strategy.

See `alternate_learning/README.md` for implementation and training details.

## Knowledge Graph Configurations

### Standard 3-Relation KG

The standard Fashion Knowledge Graph contains:

```text
compatible_with
belongs_to
belongs_to_brand
```

where:

- `compatible_with` models cross-category `also_buy` relationships;
- `belongs_to` connects products to Fashion macro-categories;
- `belongs_to_brand` connects products to their brand.

### Enriched 5-Relation KG

The enriched KG adds:

```text
belongs_to_price_tier
belongs_to_pop_tier
```

Price values are discretized into quartiles, while product popularity is derived from the Amazon product rank.

This configuration is used to investigate whether additional structured item metadata improves joint recommendation performance.

## Experimental Variants

The Fashion experiments investigate several dimensions of the proposed architecture.

### Standard Alternate Learning

Joint optimization of:

```text
Task A: TransE
Task B: SASRec
```

through a shared item embedding matrix.

Different task scheduling strategies are evaluated, including:

```text
one_to_one
epoch
adaptive
```

where applicable.

### 5-Relation Knowledge Graph

Tests whether enriching the Knowledge Graph with price and popularity information improves sequential recommendation performance.

### KG Ablation Study

The contribution of individual KG components is investigated using:

```text
no_brand
no_category
no_compatible
```

Each ablation uses an independently trained TransE checkpoint.

### Fashion-Heavy

Tests an alternative user-selection strategy designed to produce user histories with stronger cross-category information.

This configuration has its own:

- preprocessed interaction data;
- Knowledge Graph;
- TransE models;
- SASRec model;
- joint-training experiments.

## Evaluation

Sequential recommendation performance is evaluated primarily using:

```text
Recall@20
NDCG@20
```

SASRec model selection is always based on validation performance.

For HPO runs that additionally save a test-selected checkpoint, `best_test.pth` is treated only as a diagnostic artifact.

Downstream experiments use:

```text
best_valid.pth
```

for SASRec initialization.

Knowledge Graph embedding quality is evaluated using link-prediction metrics including:

```text
MRR
MR
Hits@1
Hits@3
Hits@10
```

Both naive and type-constrained evaluations are stored for TransE experiments.

## Main Experimental Results

The Fashion experiments evaluate the proposed shared-embedding architecture on
two different dataset configurations:

- **Fashion-Random:** random user sampling;
- **Fashion-Heavy:** user selection prioritizing category diversity and
  interaction activity.

All final multi-seed comparisons use the same five random seeds:

```text
2020
42
1024
999
2024
```

Sequential recommendation performance is reported using Recall@20 and NDCG@20.

### Fashion-Random - Standalone SASRec

The standalone SASRec model uses a 64-dimensional representation and Cross-Entropy loss.

Across five seeds:

| Model | Recall@20 | NDCG@20 |
|---|---:|---:|
| SASRec baseline | 0.0966 ± 0.00023 | 0.0889 ± 0.00016 |

### Fashion-Random - Alternate Learning

Both BPR and Cross-Entropy were evaluated as Task B objectives during the initial alternate-learning experiments.

| Task B loss | Scheduling | Recall@20 | NDCG@20 |
|---|---|---:|---:|
| BPR | `one_to_one` | 0.0946 | 0.0501 |
| BPR | `epoch` | 0.1017 | 0.0563 |
| CE | `one_to_one` | 0.1039 | 0.0908 |
| CE | `epoch` | 0.1039 | 0.0914 |

Cross-Entropy clearly improves ranking quality over BPR, especially in terms of NDCG@20, and is therefore used for the final Fashion experiments.

The final five-seed results are:

| Model | Scheduling | Recall@20 | NDCG@20 |
|---|---|---:|---:|
| SASRec baseline | - | 0.0966 ± 0.00023 | 0.0889 ± 0.00016 |
| KGSEQ | `one_to_one` | **0.10366 ± 0.00044** | **0.09083 ± 0.00041** |
| KGSEQ | `epoch` | 0.10324 ± 0.00057 | 0.09032 ± 0.00065 |

Both alternate-learning schedules outperform standalone SASRec.

Paired Wilcoxon signed-rank tests between the hybrid models and the standalone SASRec baseline give:

```text
Recall@20: p = 0.0312
NDCG@20:   p = 0.0312
```

for both scheduling strategies.

The difference between `one_to_one` and `epoch` is not statistically significant:

| Comparison | Recall@20 p | NDCG@20 p |
|---|---:|---:|
| `one_to_one` vs `epoch` - one-sided | 0.0625 | 0.0938 |
| `one_to_one` vs `epoch` - two-sided | 0.1250 | 0.1875 |

### Fashion-Random - Knowledge Graph Ablation

The isolated TransE ablation investigates the contribution of each of the three original Knowledge Graph relations.

| KG configuration | MRR |
|---|---:|
| Full | 0.1057 |
| No brand | 0.0907 |
| No category | 0.0946 |
| No `compatible_with` | **0.0023** |

Removing the compatibility relation produces by far the strongest degradation in isolated link-prediction performance.

Selected ablations were subsequently evaluated in the alternate-learning architecture using a single seed.

| Configuration | Scheduling | Recall@20 | NDCG@20 |
|---|---|---:|---:|
| No brand | `epoch` | 0.1162 | 0.1063 |
| No brand | `one_to_one` | 0.1165 | 0.1065 |
| No category | `epoch` | 0.1235 | 0.1075 |
| No category | `one_to_one` | 0.1234 | 0.1079 |
| No `compatible_with` | `epoch` | 0.1209 | 0.1083 |
| No `compatible_with` | `one_to_one` | 0.1209 | 0.1086 |
| Full | `epoch` | 0.1235 | **0.1100** |
| Full | `one_to_one` | 0.1235 | 0.1099 |

These ablation experiments are single-seed analyses and should therefore be interpreted as diagnostic comparisons rather than multi-seed performance estimates.

### Fashion-Heavy - Standalone SASRec

Fashion-Heavy uses a different user-selection procedure from Fashion-Random and therefore requires an independently tuned SASRec model.

The selected SASRec configuration uses:

```text
hidden size       = 128
layers            = 2
attention heads   = 8
learning rate     = 0.000316
hidden dropout    = 0.3
attention dropout = 0.1
weight decay      = 1e-5
loss              = Cross-Entropy
```

Across five seeds:

| Model | Recall@20 | NDCG@20 |
|---|---:|---:|
| SASRec baseline | 0.09088 ± 0.00034 | 0.07734 ± 0.00023 |

### Fashion-Heavy - Alternate Learning

Two Knowledge Graph configurations are evaluated:

```text
3-rel KG
5-rel KG
```

The final experiments use `one_to_one` scheduling.

| Model | KG | Recall@20 | NDCG@20 |
|---|---|---:|---:|
| SASRec baseline | None | 0.09088 ± 0.00034 | 0.07734 ± 0.00023 |
| KGSEQ | 3-rel | **0.09796 ± 0.00028** | **0.08046 ± 0.00014** |
| KGSEQ | 5-rel | 0.09783 ± 0.00035 | 0.08041 ± 0.00008 |

Both Knowledge Graph configurations outperform standalone SASRec.

Paired Wilcoxon signed-rank tests give:

```text
3-rel vs SASRec
Recall@20: p = 0.0312
NDCG@20:   p = 0.0312

5-rel vs SASRec
Recall@20: p = 0.0312
NDCG@20:   p = 0.0312
```

The direct comparison between the 3-rel and 5-rel configurations is not statistically significant:

```text
Recall@20: p = 0.8125
NDCG@20:   p = 0.6250
```

The engineered price-tier and popularity-tier relations therefore do not provide a measurable downstream recommendation benefit in this experiment.

### Fashion-Heavy - Isolated TransE Ablation: 3 Relations

| KG configuration | MRR | Hits@10 |
|---|---:|---:|
| Full 3-rel graph | 0.1010 | 0.1840 |
| Without `belongs_to` | 0.0874 | 0.1707 |
| Without `belongs_to_brand` | 0.0844 | 0.1562 |
| Without `compatible_with` | **0.0004** | **0.0006** |
| `compatible_with` only | 0.0654 | 0.1250 |

Again, removing `compatible_with` produces the strongest degradation.

### Fashion-Heavy - Isolated TransE Ablation: 5 Relations

| KG configuration | MRR | Hits@10 |
|---|---:|---:|
| Full 5-rel graph | 0.1033 | 0.1852 |
| Without `belongs_to` | 0.0938 | 0.1672 |
| Without `belongs_to_brand` | 0.0875 | 0.1453 |
| Without `belongs_to_pop_tier` | 0.1050 | 0.1881 |
| Without `belongs_to_price_tier` | 0.1041 | 0.1788 |
| Without `compatible_with` | 0.0005 | 0.0006 |
| `belongs_to` + `belongs_to_pop_tier` | 0.0005 | 0.0012 |
| `belongs_to_pop_tier` + `compatible_with` | 0.0757 | 0.1337 |
| `belongs_to` + `belongs_to_brand` + `compatible_with` | **0.1122** | **0.1875** |
| `compatible_with` + `belongs_to_brand` | 0.0989 | 0.1771 |
| `compatible_with` + `belongs_to` | 0.0902 | 0.1516 |
| `compatible_with` only | 0.0688 | 0.1215 |
| `compatible_with` + `belongs_to_brand` + `belongs_to_price_tier` | 0.0926 | 0.1632 |
| `compatible_with` + `belongs_to` + `belongs_to_pop_tier` | 0.0872 | 0.1499 |

Interestingly, the configuration retaining `belongs_to`, `belongs_to_brand`, and
`compatible_with` performs better than the complete 5-relation graph in isolated
TransE evaluation:

```text
MRR:     0.1122 vs 0.1033
Hits@10: 0.1875 vs 0.1852
```

However, this advantage does not transfer to downstream sequential recommendation.

### Fashion-Heavy - Downstream Ablation

Selected Fashion-Heavy variants were evaluated using seed 2020 and `one_to_one` scheduling.

| KG configuration | KG | Recall@20 | NDCG@20 |
|---|---|---:|---:|
| Full graph | 5-rel | 0.09786 | 0.08039 |
| Without `compatible_with` | 5-rel | 0.09384 | 0.07900 |
| Without price-tier and popularity-tier | 5-rel | 0.09766 | 0.08033 |
| `compatible_with` + `belongs_to_brand` | 5-rel | 0.09728 | 0.08024 |
| Full graph | 3-rel | 0.09822 | 0.08060 |
| Without `belongs_to` | 3-rel | 0.09692 | 0.08009 |

Removing the price-tier and popularity-tier relations improves isolated TransE link-prediction performance, but this advantage does not persist in downstream recommendation.

Removing `compatible_with` from the five-relation graph reduces Recall@20 from 0.09786 to 0.09384 and NDCG@20 from 0.08039 to 0.07900, corresponding to relative reductions of approximately 4.1% and 1.7%, respectively.

These downstream ablations use a single seed and should therefore be interpreted
as diagnostic comparisons. Nevertheless, the result is consistent with the B2B
findings and further highlights the importance of compatibility information
across both domains.

This highlights an important result of the ablation study:

```text
better isolated Knowledge Graph embedding performance
does not necessarily imply
better downstream recommendation performance
```

Across the Fashion experiments, compatibility remains the most important structural relation, while adding more Knowledge Graph relations does not automatically improve recommendation quality.



## Reproducibility

The Python source code uses paths derived from the repository structure rather than user-specific local filesystem locations.

HPC scripts use generic placeholders for cluster-specific filesystem paths and must be adapted to the target HPC environment before execution.

Large intermediate results, obsolete checkpoints, and debugging artifacts are not part of the cleaned repository.

The retained files correspond to the datasets, checkpoints, configurations, and experiment outputs required to reproduce the final Fashion experiments.

## Relationship with the B2B Experiments

The Fashion experiments are designed as a generalization study of the knowledge-enhanced sequential recommendation architecture originally developed for the B2B domain.

The two domains differ substantially in:

- number of users and items;
- interaction density;
- sequence lengths;
- repeat behavior;
- available structural information;
- semantics of the Knowledge Graph.

The Fashion experiments therefore test whether improvements obtained through joint KG and sequential learning transfer beyond the original industrial B2B scenario.
